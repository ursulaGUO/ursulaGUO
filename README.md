## 🔍 Selected Projects

### [📈 Alpaca-Real-Time-Quant-Strategy](https://github.com/ursulaGUO/Alpaca-Real-Time-Quant-Strategy)
An end-to-end quantitative trading pipeline using the Alpaca API. Features:
- Real-time sentiment extraction from social media
- Technical indicators and feature engineering
- Dynamic portfolio rebalancing with backtesting support
- AWS-hosted infrastructure for deployment

### [👄 LipReading_CV](https://github.com/ursulaGUO/LipReading_CV)
Developed a full pipeline for word-level visual speech recognition:
- Data preprocessing using FFmpeg and Montreal Forced Aligner
- Temporal modeling using 3D CNNs
- Word-level classification and evaluation on benchmark datasets
